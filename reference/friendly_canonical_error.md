# Translate an 'imuGAP' canonicalizer error into a friendly message

Translate an 'imuGAP' canonicalizer error into a friendly message

## Usage

``` r
friendly_canonical_error(sheet, e)
```

## Arguments

- sheet:

  character; which sheet the canonicalizer was checking.

- e:

  the captured condition.

## Value

character scalar problem message.
