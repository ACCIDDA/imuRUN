# Agent Guidelines for imuRUN

This document provides concise instructions and rules for AI coding assistants working in the `imuRUN` repository. For full developer documentation and CI architecture, see [CONTRIBUTING.md](CONTRIBUTING.md).

---

## 1. Core Architecture & Invariants

* **Package Purpose**: **Routine-Use Notebooks** (`imuRUN`) provides a user-facing CLI and spreadsheet-friendly workflow runner for [`imuGAP`](https://github.com/ACCIDDA/imuGAP). It accepts single-file `.xlsx` workbooks (or loose CSV/RDS input directories) containing observations, locations, optional sampler configuration, and evaluation targets, validates inputs against a friendly schema, delegates model fitting to `imuGAP::sampling()`, generates posterior coverage predictions for arbitrary age spans/locations, and produces amended Excel workbooks (with styled `results` tab) or clean CSV summaries.
* **Excel Engine (`openxlsx2`)**:
  * All `.xlsx` reading, sheet inspection, workbook modification/amendment, style preservation (freezing, autofilters, dropdowns), and writing are handled exclusively via `openxlsx2`.
  * `readxl` and `writexl` are intentionally **not** dependencies.
* **CLI and R Interfaces**:
  * The R functions are the primary interface: [run_fit()](file:///home/holism/workspaces/ACCIDDA/imurun/R/run.R), [validate_inputs()](file:///home/holism/workspaces/ACCIDDA/imurun/R/validate.R), [imurun_init()](file:///home/holism/workspaces/ACCIDDA/imurun/R/init.R), [read_inputs()](file:///home/holism/workspaces/ACCIDDA/imurun/R/loaders.R), [write_results_workbook()](file:///home/holism/workspaces/ACCIDDA/imurun/R/results.R).
  * The CLI wrapper is installed onto `PATH` via `imuRUN::install_cli()` (creates a symlink on Unix or `imurun.cmd` shim on Windows pointing to `inst/scripts/imurun.R`).
* **Required Evaluation Targets**:
  * Every input must define evaluation targets (`target` sheet or `target.csv`), specifying requested locations, years, and age spans (`age_low` to `age_high`).
* **Workbook Preservation**:
  * When amending an existing workbook in-place with model results, `imuRUN` preserves non-data tabs (e.g. `instructions`), column filters, and formatting.
* **Untracked Artifacts**:
  * `man/*.Rd` and `docs/` are generated by `roxygen2` / `pkgdown` and are untracked in git.
  * `NAMESPACE` is tracked in git.

## 2. Coding, Error Handling & Documentation Standards

* **Formatting & Linting**:
  * Format code with `just format` (`air`).
  * Verify lint compliance with `just lint` (`air` and `lintr`).
  * Maximum line length is **100 characters**.
* **Error Handling & Friendly Validation**:
  * In [validate_inputs()](file:///home/holism/workspaces/ACCIDDA/imurun/R/validate.R) and [check_all_inputs()](file:///home/holism/workspaces/ACCIDDA/imurun/R/loaders.R), collect and report **all** missing sheets, columns, or invalid values at once rather than failing on the first error.
  * **Typography**: Use backticks (`` `code` ``) for function/argument/symbol names and single quotes (`'value'`) for user string values, column names, sheet names, and file paths.
* **Markdown Documentation**:
  * `roxygen2` markdown mode is enabled (`Roxygen: list(markdown = TRUE)`).
  * Use markdown links and formatting in roxygen tags.
* **Test Suite (`testthat`)**:
  * Maintain high test coverage (>90%) across all R modules.
  * Fixtures (`example.xlsx`, `example_corrupt.xlsx`, `example_dir`) are generated by `data-raw/make_workbooks.R` (`just data`).

## 3. Common Development Commands

Use `just` recipes for development workflows:

```sh
just format        # Format R code (air)
just lint          # Lint R code (air + lintr)
just docs          # Regenerate man/*.Rd
just install       # Install package into R library
just test          # Run full test suite
just test-fast     # Run test suite, stopping on first failure
just coverage      # Check code coverage (covr)
just spell         # Check spelling across docs and vignettes (spelling)
just data          # Regenerate template/example workbooks and test fixtures
just render        # Render HTML and PDF vignettes
just site          # Fast build of pkgdown site into docs/ (no reinstall)
just site-quick    # Alias for fast site build
just site-full     # Full build of pkgdown site with package reinstall
just site-preview  # Preview pkgdown site on localhost:8000
just check-cran    # Run R CMD check --as-cran
```
